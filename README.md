# Cyfef — Personal Portfolio

一个为 Cyfef 设计的响应式个人主页，采用编辑感布局与 Bento 卡片组合。页面目前使用可直接替换的占位内容，适合逐步补充个人介绍、项目经历与联系方式。

## 本地预览

直接打开 `index.html`，或在项目目录运行任意静态文件服务器。

## 自定义位置

- `index.html`：个人介绍、作品、经历、邮箱与社交链接
- `styles.css`：颜色、字体、布局和动效
- `script.js`：主题切换、滚动动画和光标光晕

## 部署

这是一个纯静态网站，可直接部署到 GitHub Pages、Netlify 或 Vercel。
